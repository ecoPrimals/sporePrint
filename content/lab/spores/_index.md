The pseudoSpore gallery hosts self-contained, reproducible computation packages
emitted by validated springs. Each pseudoSpore contains raw data, derivation
commands, configuration files, provenance braids, and integrity checksums.

**Verification protocol:** Download the lithoSpore archive, run the derivation
commands in `TRANSLATE.md`, compare outputs against `receipts/checksums.blake3`.
No trust required — every result is independently derivable from raw data.

## Available pseudoSpores

Browse the gallery below. Each page shows the domain profile, module validation
status, provenance chain, and a link to download the lithoSpore archive.
