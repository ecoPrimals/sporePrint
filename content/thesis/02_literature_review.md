## Overview

Four literatures have developed largely in isolation:

1. **Extremophile biology** — Brock's *Thermus aquaticus*, thermophilic adaptation, constraint-shaped enzymes
2. **Experimental evolution** — Lenski's LTEE, 75,000+ generations, fitness dynamics, citrate innovation
3. **Type theory and evolutionary computation** — genetic algorithms, fitness landscapes, type-directed search
4. **AI-assisted development** — LLM code generation, copilot studies, constraint-free vs. constrained paradigms

No existing framework connects biological constraint to type-theoretic constraint with multi-domain empirical validation. This thesis fills that gap.
