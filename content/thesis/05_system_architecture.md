## Sovereign Scientific Computing

The ecoPrimals platform consists of {{ total_stat(stat="total_primals") }} primals coordinated via capability-based composition. The central claim: this architecture **emerged from constraint**, not upfront design.

Tower Atomic (pure Rust HTTPS), the bonding model, and NUCLEUS deployment all arose when the Pure Rust directive eliminated OpenSSL. Each architectural decision was forced by the constraint environment, not chosen from a design catalog.
