The commons

The pages of the sporePrint name data files, scripts and feeds. This is every one of them: held here with its hash and where it came from, or listed with the reason it is not. Whoever holds a copy of this repository holds the files, and can check them.

Check a copy

The manifest is manifest.json: one entry per file, with its SHA-256. With a copy of the repository:

python scripts/commons.py check                                  # this copy
python scripts/commons.py check https://sporeprint.primals.eco   # what the site serves

Held back means the file was found and not copied: it names an address inside the house, carries something that looks like a login or a secret, or is larger than 5 MB. Undecided means several different files carry the name and the page does not say which (undecided.json lists them). Not found means no tree the gathering was given holds a file of that name.
